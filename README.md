
# Healthcare Operations & Patient Analytics Dashboard

A comprehensive multi-page Power BI business intelligence suite analyzing healthcare operations, patient demographics, chronic conditions, and facility performance.

## Project Deliverables:
- **Power BI Dashboard (.pbix):** Features custom tooltips, drill-through navigation, bookmarks, and conditional formatting.
- **Executive Dashboard PDF:** High-level summary report for executive stakeholders.
- **Advanced Features:** Includes Time Intelligence (YTD), Decomposition Trees, Key Influencers, and Forecasting.
